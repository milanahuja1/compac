Create a simple webpage for car owners. A car owner should be able to see information about their car's battery, e.g. battery level and whether it is currently charging or not.
The webpage should give them the ability to start / stop charging the battery using REST APIs. Optionally they should also be able to set a charging schedule e.g. I want my car to start charging at 2 AM.

Tools - Use your own Azure environment. You should be able to use free limits / tiers
Use Azure IoT Hub to connect to your simulated car (car can be simulated by a small console program using C# IoT Device SDK)
The console program should simulate the battery percentage and charging state
Use Azure Functions to process messages from IoT Hub
Use your choice of framework / vanilla JS for front end

Please upload your code to a git repository and send us the link.
